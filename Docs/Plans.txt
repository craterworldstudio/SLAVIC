Goal:
Create a continuously running artificial mind that learns from an environment,
builds internal representations of objects/events, forms memories, and generates
its own thoughts and actions without predefined scripts or random action selection.

Principle
1. Continuous cognition (system always running)
2. Learning from observation
3. Prediction-based reasoning
4. Memory-based learning
5. Attention through competition (Global Workspace)

Environment Type: Object World

World properties:
- Objects appear and disappear
- Objects have properties (color, type, state)
- Events occur over time
- Agent can observe environment

t1: object A appears (color=red)
t2: object B appears (color=blue)
t3: object A disappears

Capabilities (Phase 1):

1. Detect objects
2. Detect changes
3. Store memories
4. Predict next events
5. Focus attention on unexpected events
6. Rewire Itself
